# DevLens

DevLens is a full-stack AI-powered developer analytics and productivity platform designed to help developers monitor workflows, track coding activity, analyze repositories, and gain intelligent insights into their development process.

The project combines frontend development, backend APIs, AI/ML capabilities, and scalable architecture into a single developer-focused platform.

---

# Features

## Current Features

- Modern responsive frontend UI
- Backend API integration
- Repository/project analytics foundation
- Developer productivity tracking
- Scalable project structure
- Clean modular architecture
